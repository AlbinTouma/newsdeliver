# Newsdeliver 

Newsdeliver is a Python package that can scrape RSS feeds inlcuding Google News feed. 
It's a tool that allows you to fetch articles from different RSS feeds.
If you find the tool useful, please support the package by hitting the star on Github. 
Your support helps keep the project going!

Use Newsdeliver to build a large corpus of news articles from different rss feeds in parallel.
The package also supports Google News RSS and resolves the Google News redirect to the publishing source.
Both static and javascript rendered sites are supported. Installing playwright is optional.
